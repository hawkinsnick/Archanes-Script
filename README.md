# Archanes Script Corpus

A provenance-first corpus for the earliest Archanes writing evidence and the so-called Archanes Formula. Competing scholarly definitions of the corpus and signary are first-class evidence; this project does **not** force consensus where scholarship lacks it.

The corpus is cross-linked conceptually to Cretan Hieroglyphic and Linear A but does not silently merge Archanes into either system.

See `research/pre-expert-maximum.json`, `docs/ROADMAP.md`, and `ai-skill/SKILL.md`.
