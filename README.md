# Archanes Script Corpus

A provenance-first corpus for the earliest Archanes writing evidence and the so-called Archanes Formula. Competing scholarly definitions of the corpus and signary are first-class evidence; this project does **not** force consensus where scholarship lacks it.

The corpus is cross-linked conceptually to Cretan Hieroglyphic and Linear A but does not silently merge Archanes into either system.

See `research/pre-expert-maximum.json`, `docs/ROADMAP.md`, and `ai-skill/SKILL.md`.


## Offline corpus browser
Run `python scripts/build_corpus_browser.py` to generate `workbench/corpus-browser.html`. It searches only files explicitly admitted by `research/browser-sources.json`. Browser admission requires rights/provenance review; never recursively ingest restricted or raw upstream material. Display does not establish decipherment, source independence, or expert validation.


## Linear A method-parity gate
The project now preserves Decorte's complete 16-object authority corpus, competing corpus/script models, authority-specific signaries/formula patterns, explicit source lineage and rights boundaries, plus browser/API/export/validation interfaces. It does not assert a consensus independent Archanes script. See `docs/RIGHTS-ONLY-READINESS.md` and `research/residual-blocker-ledger.json`.
